# Superseded Items

Use this directory for numbered items, iterations, and design docs that were
real planning artifacts but no longer describe the current system.

Keep the original item ID when one exists. A superseded archive should briefly
say what replaced it so future agents do not re-open old design branches by
accident.

Aggregate historical registers use `rollup-*` filenames instead of item IDs.
Their headers should include a short crosswalk to the numbered items that
replaced them.
