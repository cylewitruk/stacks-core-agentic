# Completed Items

Completed item archives use the same `NNNN-slug.md` filename as the item and
its optional design doc.

Each archive should contain, at minimum:

1. Item metadata and original problem/scope.
2. What shipped.
3. Validation evidence.

Add these when they apply:

1. The design doc contents, if one existed and remains useful.
2. Deviations from the design.
3. Follow-up items moved back to backlog or a new iteration.
