# Design Docs

Optional detailed plans for backlog or iteration items live here.

Backlog entries and iteration item lists should stay scannable and link here
when an item has worked-through design detail. A design doc is not required for
trivial tasks.

Design docs use the same item ID as their backlog/iteration entry:

```text
planning/design/0028-optimizer-memory.md
```

Use this directory for living design detail. Once the work ships, consolidate
the backlog/iteration entry and this design into one archive file with the same
ID, then remove the live design doc or move it to `planning/archive/superseded/`
if it remains useful historical context.
